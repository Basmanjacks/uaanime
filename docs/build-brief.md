# uaanime — build brief

Порожня директорія. Побудуй продукт, а не прототип. **Спочатку вертикальний зріз, потім ширина.**
Не зупиняйся на архітектурних документах — код має запускатися і грати відео.

---

## 1. Продукт

Термінальний застосунок для перегляду аніме **українською** (озвучення та субтитри).

```
uaanime → Продовжити → Enter → грає
```

Користувач ніколи не бачить слів «провайдер», «відеохост», «екстрактор», «m3u8».
Головна відмінність від ani-cli: **стан**. Ми пам'ятаємо, на чому ти зупинився і чию озвучку любиш.

## 2. Стек — зафіксовано, не обговорюється

| Що | Рішення |
|---|---|
| Мова | Go 1.23+ |
| TUI | Charm **v2**: `charm.land/bubbletea/v2`, `charm.land/bubbles/v2`, `charm.land/lipgloss/v2` |
| HTTP/парсинг | `net/http` + `goquery` |
| Плеєр | зовнішній **mpv** через JSON IPC |
| Сховище | JSON-файли, атомарний запис (tmp + rename) |
| Пакування | GoReleaser → GitHub Releases + Homebrew tap + `go install` |
| CI | GitHub Actions: build, test, `gofmt -l`, `go vet`, `golangci-lint` |

**Дозволені залежності** (все інше — обґрунтувати окремо, за замовчуванням «ні»):
`charm.land/bubbletea/v2`, `charm.land/bubbles/v2`, `charm.land/lipgloss/v2`,
`PuerkitoBio/goquery`, `golang.org/x/text`, `stretchr/testify` (лише тести).

⚠️ **Тільки v2.** Charm випустив другі мажорні версії у лютому 2026 зі зміненими шляхами
імпорту (`charm.land/...` замість `github.com/charmbracelet/...`). Твої тренувальні дані
майже напевно містять v1 — не пиши v1. Перед першим рядком TUI-коду звірся з актуальним
upgrade guide.

Два наслідки v2, які треба врахувати одразу:
- визначення профілю кольору і зниження якості ANSI вбудовані та ввімкнені за замовчуванням — не роби це руками;
- `AdaptiveColor` прибрано. Світлий/темний фон обирається явно (`compat.HasDarkBackground`).
  Світлий термінал — не крайній випадок, це половина людей.

**Заборонено:** SQLite/cgo, headless-браузер, chromedp, Electron, демони, власний бекенд, обов'язковий акаунт, будь-яка телеметрія.

Один статичний бінарник. Холодний старт < 100 мс.

### Інтерфейс: CLI-перший, один список

Не будуй «TUI» у сенсі застосунку з екранами. Будуй **один компонент списку**, який
перевикористовується з різним вмістом: продовжити, пошук, серії, історія, оновлення.

**Правило:** якщо екран не вкладається у формат «заголовок + список + один рядок підказки» —
він не будується. Заборонено: панелі, сайдбари, вкладки, розділений екран, миша,
кастомні скролбари, прогрес-бари на весь екран, ASCII-банери.

fzf не використовуємо — `bubbles/list` дає фільтрацію з коробки, зовнішня залежність зіпсує
історію встановлення. Esc = крок назад, не вихід з усього.

Усі кольори й відступи — в одному файлі теми (`internal/ui/theme.go`). У решті коду
жодного хардкоду кольору. Іконки Nerd Font опційні, з автоматичним відкатом на текст.

## 3. Доменна модель

Повна архітектура джерел — у `docs/providers.md` (провайдери, екстрактори, злиття тайтлів,
ланцюжок fallback, contract-тести). Тут — мінімум, потрібний для старту.

Це ядро. Провайдер-специфічна логіка не має витікати за межі `internal/provider`.

```go
Title    { ID, Slug, TitleUA, TitleOrig, Year, Type, Episodes, Status, Provider }
Episode  { Number, Title, Releases []Release }
Release  { Studio string, Kind Kind }      // Kind: dub | sub | multi
Stream   { Host, Quality, URL, Headers map[string]string, TTL }

Progress { TitleID, Episode, PositionSec, DurationSec, Completed bool, WatchedAt }
Entry    { TitleID, State (watching|planned|completed), StudioPin, KindPin, LastEpisode }
```

Ключове: **`Release` — це пара (студія, тип)**. Одна серія на українських сайтах часто має 3–5 варіантів озвучення від різних студій плюс саби. Це не деталь реалізації, це головна фіча.

**Ніколи не перекладай назви студій.** FanVoxUA залишається FanVoxUA.

## 4. Вибір озвучення — серце продукту

Порядок розв'язання при відкритті серії:

1. закріплена студія для цього тайтлу (`StudioPin`)
2. глобальна улюблена студія
3. глобальна перевага типу (за замовчуванням `dub`)
4. будь-яке інше **українське озвучення**
5. українські **субтитри**
6. якщо після цього лишається >1 кандидата — спитати один раз і закріпити вибір за тайтлом

**Жорстке правило:** якщо доступне будь-яке інше українське озвучення — не перемикати користувача на субтитри. Ніколи.

Питати повторно за той самий тайтл — баг.

## 5. Плеєр

Тільки mpv у v1. Абстракція `Player` існує, реалізація одна.

```
mpv --input-ipc-server=<sock> --start=<sec> --force-media-title="Фрірен · 17"
    --no-terminal --http-header-fields="Referer: <origin>,User-Agent: <ua>" <url>
```

Через IPC-сокет: `get_property time-pos`, `duration`; підписка на подію `end-file`
(розрізняй `eof`, `quit`, `error` — це різні сценарії для UI).

Багато українських відеохостів віддають потік лише з правильним `Referer`. Це не обхід
захисту — це звичайний заголовок; але означає, що `Stream` мусить нести свої `Headers`
аж до запуску плеєра. Не втрать їх у шарах.

Windows (named pipes) — поза v1, але не закладай POSIX-шляхи в API.

## 6. Надійне збереження прогресу

Не покладайся на чисте завершення.

- окремий крихітний файл-журнал `state/current.json` (~200 байт) переписується атомарно раз на **5 секунд** під час гри;
- на `end-file` та на старті застосунку журнал зливається в `library.json` і видаляється;
- `kill -9` під час перегляду → втрата не більше 10 секунд.

Не переписуй усю бібліотеку кожні 5 секунд.

Завершеною серія вважається на **90%** тривалості (налаштовується). Далі — авто-фокус на наступній.

## 7. Headless-режим — обов'язково

Без цього ти не зможеш перевірити сам себе, бо TUI не запускається без TTY.
Реалізуй **до** TUI, не після:

```
uaanime search "фрірен" --json
uaanime episodes <title-id> --json
uaanime resolve <title-id> <ep> --json     # список кандидатів-потоків, без відтворення
uaanime play <title-id> <ep> --dry-run     # друкує підсумкову команду mpv
uaanime doctor --json
uaanime export > backup.json
uaanime import backup.json
```

`UAANIME_FIXTURES=1` → провайдер читає збережений HTML із `testdata/` замість мережі.
`make record-fixtures` → перезаписує фікстури з живого сайту (запускається вручну, не в CI).

## 8. Фази. Не переходь далі, поки критерій не виконано

**Phase −1 — референси.** Прочитай `Gridi-1143/ani-ukr` (POSIX-скрипт для anitube.in.ua, GPL-3.0)
і `vypivshiy/ani-cli-ru` (Python, парсери винесені окремим модулем). Випиши висновки **своїми
словами** в `docs/prior-art.md` — список рішень, не фрагменти коду. Далі до їхнього коду не
повертайся. Селектори для AniTube виводь з живої сторінки сайту, не з їхнього скрипта.
Код звідти не копіюємо: ani-ukr під GPL-3.0. `MrIkso/AnitubeApp` не відкривай узагалі — AGPL-3.0.
*Критерій: `docs/prior-art.md` існує, у коді немає нічого запозиченого.*

**Phase 0 — ревізія стеку.** Стек вище — обґрунтоване рішення, а не догма. Перед першим
рядком коду перевір його своїми свіжими знаннями і напиши `docs/adr-001-stack.md`: що
залишаєш, що міняєш, чому.

Критерії, за якими судити (у цьому порядку):
1. простота встановлення для кінцевого юзера (ціль: одна команда, без рантаймів);
2. холодний старт < 100 мс;
3. мала кількість залежностей і легкість підтримки парсерів;
4. якість і актуальність TUI-екосистеми;
5. зручність для агентної розробки.

Що можна змінювати: конкретні бібліотеки, версії, структуру пакетів, формат сховища.
Що змінювати не можна без прямого дозволу: зовнішній плеєр замість власного, локальне
зберігання без бекенда, відсутність акаунтів і телеметрії, один бінарник як ціль дистрибуції.

Якщо лишаєш як є — напиши один абзац «розглянув, лишаю, бо…» і йди далі. Якщо міняєш —
онови цей бриф і `AGENTS.md` під нове рішення. **Часовий бюджет: одна ітерація.**
Після запису ADR стек зафіксовано, до питання не повертаємось.

**Phase 0.5 — грає.** Хардкод одного тайтлу. `uaanime play <slug> 1` відкриває mpv з українською доріжкою.
*Критерій: відео реально грає.*

**Phase 1 — провайдер.** Пошук, список серій, список релізів, резолв потоку. Фікстури + офлайн-тести.
*Критерій: `go test ./...` проходить без мережі.*

**Phase 2 — стан.** Прогрес, resume, завершення, закріплення студії.
*Критерій: вихід на 14:32 → наступний запуск пропонує продовжити з 14:2x.*

**Phase 3 — TUI.** Головний екран, пошук, екран тайтлу, список серій із станами.
*Критерій: усе з фаз 1–2 доступно з клавіатури, без прапорців.*

**Phase 4 — бібліотека.** Список перегляду, історія, оновлення (нові серії), `doctor`, export/import.

**Phase 5 — реліз.** README, GoReleaser, tap, CI, LICENSE.

## 9. Інваріанти

1. Жоден `panic` не долітає до користувача. `recover` у корені + відновлення терміналу через `defer` на **всіх** шляхах виходу. Зламаний після виходу термінал — критичний баг.
2. Мережа за інтерфейсом. Юніт-тести ніколи не ходять у мережу.
3. Помилка провайдера ≠ помилка мережі ≠ немає потоку. Три різні повідомлення.
4. Fallback між джерелами автоматичний і мовчазний: `Джерело недоступне, пробую інше…`. HTTP-код показуємо тільки в `--debug`.
5. Офлайн: список перегляду, історія, прогрес і кеш метаданих відкриваються завжди.
6. Не кешуємо URL потоків (вони протухають). Кешуємо метадані з TTL.
7. Український інтерфейс, але рядки винесені в `internal/i18n` з самого початку — англійська додається пізніше без рефакторингу.
8. Не виконуємо нічого, отриманого з сайту, як код. Зовнішні дані — недовірені.
9. Ніяких механізмів обходу автентифікації, paywall, DRM чи CAPTCHA.

## 10. Пошук

Українські сайти шукають по українській назві. Запит `frieren` там не знайде «Фрірен».

- шукай на провайдері як є;
- якщо порожньо — спробуй нормалізований варіант (нижній регістр, прибрані діакритики, транслітерація);
- локальний aliases-кеш: усі бачені раніше пари (укр. назва ↔ оригінал) зберігаються і шукаються офлайн;
- нечітке ранжування (Levenshtein/трiграми) застосовується **до результатів провайдера**, не замість запиту;
- 5 останніх запитів зберігаються, є очищення.

## 11. Поза скоупом v1

Прибрано свідомо — не реалізовувати, навіть якщо здається легким:
AniList/MAL, постери в терміналі, окремі «Обране», пропуск опенінгів, теми, синхронізація,
рекомендації, завантаження серій, метадані з зовнішніх API.

«Режим запою» — це не окрема фіча, а значення налаштування `autoplay: ask|always|never`.
Не створюй два поняття для одного.

Налаштувань має бути ≤ 8. Якщо додаєш дев'яте — прибери інше.

## 12. Definition of done

- [ ] `brew install …` → `uaanime` → перегляд без жодного конфіга
- [ ] холодний старт < 100 мс, перший екран без мережі
- [ ] пошук → відео на екрані ≤ 3 дії
- [ ] `Enter` на «Продовжити» → mpv < 3 с
- [ ] точність resume ±5 с
- [ ] `kill -9` під час гри → втрачено ≤ 10 с
- [ ] `go test ./...` зелений без мережі
- [ ] мертвий відеохост → зрозуміле повідомлення, не стек-трейс
- [ ] README дає зрозуміти продукт за 60 секунд
- [ ] інтерфейс читабельний на 80×24

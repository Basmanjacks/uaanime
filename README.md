# uaanime

Дивись аніме **українською** просто з термінала: озвучення різних студій і субтитри,
з пам'яттю про те, де ти зупинився і чию озвучку любиш.

```
uaanime → Продовжити → Enter → грає
```

На відміну від ani-cli, uaanime пам'ятає **стан**:

- ▶ **Resume** — вийшов на 14:32, наступний запуск продовжить звідти (±5 с, навіть після `kill -9`);
- 🎙 **Твоя студія** — обрав FanVoxUA один раз, далі всі серії йдуть нею без питань;
- 📚 **Список перегляду й історія** — все локально, офлайн, без акаунтів і телеметрії;
- 🔔 **Оновлення** — бачиш, скільки нових серій вийшло у тайтлів, які дивишся;
- 🔁 **Fallback** — мертвий відеохост підмінюється іншим мовчки.

## Встановлення

**macOS і Linux (Homebrew):**

```bash
brew tap Basmanjacks/uaanime
brew install --cask Basmanjacks/uaanime/uaanime
```

Одна команда на обидві системи: Homebrew 6 підтримує casks і на Linux. Сторонні
tap воно автоматично не додає, тому перший рядок обов'язковий. Хочеш коротке ім'я
надалі — виконай `brew trust basmanjacks/uaanime`, і далі працюватиме просто
`brew install --cask uaanime`. Якщо ти ставив uaanime раніше формулою
(`brew install …` без `--cask`), перейди на cask:

```bash
brew uninstall uaanime && brew install --cask Basmanjacks/uaanime/uaanime
```

Для відтворення потрібен VLC або mpv. Якщо плеєра ще немає, на macOS:

```bash
brew install --cask vlc
# або
brew install mpv
```

VLC, встановлений вручну з сайту VideoLAN у `/Applications/VLC.app`, теж працює —
перевстановлювати або передавати його під керування Homebrew не потрібно.

**Без Homebrew** — через Go або tarball з Releases:

```bash
go install github.com/Basmanjacks/uaanime/cmd/uaanime@latest
# або візьми готовий бінарник із GitHub Releases
```

На Linux та інших системах встанови [VLC](https://www.videolan.org/vlc/) або
[mpv](https://mpv.io/) через пакетний менеджер своєї ОС.

`uaanime doctor` перевірить, чи все на місці.

## Використання

```bash
uaanime                # TUI: Продовжити / бібліотека / пошук / історія / каталог / налаштування
```

Клавіші в TUI:

- `↑↓` — вибір, `Enter` — відкрити, **`Esc` — крок назад** (з тайтлу — в результати
  пошуку, з них — на головну), `?` — довідка поточного екрана, `/` — пошук
  (у серіях, закладках та історії — фільтр),
  `m` — додати/прибрати закладку зі станом «в планах», `s` — на екрані серій обрати
  озвучення (закріплюється за тайтлом), `,` — налаштування, `q` — вихід.
- Екран «Грає» — плеєр слухається термінала: `Space` — пауза, `←→` — ±10 с,
  `⇧←→` — ±30 с, `N` — наступна серія, `.` — досидіти цю серію й зупинитись
  (повторне натискання вимикає обмеження), `B` — ліміт сеансу, `+`/`−` — гучність.
  Видно фактичну студію, позицію, паузу, гучність і час завершення, якщо тривалість
  відома. Адреса пульта й QR-код займають вільне місце.
- `B` задає від 1 до 12 серій **разом із поточною**, або «Без ліміту». Ліміт 2
  дограє поточну й наступну навіть при вимкненому автопереході. Ручне перемикання
  замінює поточну серію й не витрачає залишок. `.` при ліміті 2–12 встановлює 1.
  Ліміт діє лише на цей сеанс і доступний навіть із вимкненим веб-пультом.
- У довідці `Esc` закриває лише довідку; перегляд продовжується. Пауза, наступна
  серія, гучність і `.` працюють у довідці, стрілки пересувають її список.
- Екран серій: `x` — позначити серію переглянутою або скинути позначку. У заголовку —
  скільки серій лишилось і приблизно скільки це часу; у виборі озвучки (`s`) біля
  кожної студії стоїть покриття виду `9/12` — скільки серій вона озвучила.
  `W` позначає всі наявні серії перед вибраною, навіть під час фільтрації; `U`
  скасовує цю групову дію. Подальша зміна цього тайтлу або запуск перегляду
  скасовує можливість відкату. Мала `u` залишається переходом на сторінку вгору.
- Пошук: `↓` з поля відкриває 5 нещодавніх запитів, `Enter` повторює запит,
  `x` прибирає рядок з історії.
- Домівка: до трьох рядків «Продовжити» і п’яти закладок; новинки — першими.
  «Усі закладки» відкриває повний список із фільтром. Рядок «Що подивитись?»
  витягує випадковий тайтл із планів. Банер міняє орнамент за порою року.
- Історія показує по 20 тайтлів. «Показати ще» додає наступну порцію, а `/` шукає
  одразу в усій історії. Повернення з тайтлу зберігає фільтр і вибраний рядок.
- Екран «Налаштування» (рядок у секції «Ще» або `,`): плеєр, наступна серія, що
  вмикати спершу, улюблена студія, режим пульта. `←→` перемикає значення на місці,
  `Enter` відкриває список значень із поясненнями. Зміни зберігаються одразу; пульт
  перезапускається на льоту, і нова адреса видна просто на екрані.
- Бейдж «+N у <студія>» показує нові релізи закріпленої або улюбленої студії,
  зокрема пізні озвучення старих серій. За відсутності таких релізів показуються
  загальні нові серії. Перші відомі дані стають початковою базою без сповіщень.
  Відкриття тайтлу «в планах» підтверджує його релізи; для розпочатого тайтлу
  підтверджуються переглянуті або вручну позначені серії. Фонове оновлення
  перевіряє до 20 застарілих тайтлів за запуск і продовжує обхід наступного разу.
- Блоки «Топ сезону» і «Нові релізи» тягнуться з кешу (TTL 12 год) і оновлюються
  фоном — головна відкривається миттєво навіть без мережі.

Іконки — звичайний Unicode без емодзі; `UAANIME_ASCII=1` перемикає на чистий ASCII.
Шрифт задає термінал, не застосунок: якщо вирівнювання «їде», спробуйте
моноширинний шрифт із повним покриттям Unicode (наприклад, JetBrains Mono).

Headless-команди (для скриптів і перевірок):

```bash
uaanime search "фрірен" --json
uaanime episodes <title-id> --json
uaanime resolve <title-id> <серія> --json
uaanime play <title-id> <серія> [--dry-run]
uaanime doctor
uaanime export > backup.json
uaanime import backup.json
```

Дані живуть в одному каталозі (`~/Library/Application Support/uaanime` на macOS) —
`export`/`import` переносять усе.

Налаштування зручніше міняти в самому застосунку: екран «Налаштування» — рядок
у секції «Ще» на домівці або клавіша `,`. Для headless-режиму ті самі значення
лежать у `config.json` у цьому ж каталозі:

- `player`: `vlc` або `mpv`; за замовчуванням `vlc`;
- `autoplay`: `always` або `never`; за замовчуванням `always` — наступна серія
  стартує автоматично;
- `prefer_kind`: `dub`, `voiceover` або `sub`; за замовчуванням `dub` — що обирати,
  коли для серії є кілька варіантів озвучення;
- `favorite_studio`: назва студії озвучення; порожньо = не вибрано;
- `remote`: `on`, `open` або `off`; за замовчуванням `on` — веб-пульт для телефона (нижче);
  `open` — той самий пульт без токена в адресі.

## Веб-пульт

Ноутбук дзеркалиться на телевізор, а ви на дивані? Поки грає серія, uaanime тримає
крихітну сторінку в локальній мережі: пауза, ±10 і ±30 с, повзунок перемотування,
гучність, наступна серія, ліміт сеансу, «зупинити після цієї», стоп і список серій —
тап по рядку перемикає на неї. Адреса виду
`http://<ім'я-mac>.local:<порт>/r/<токен>` показується на екрані «Грає» і
друкується командою `play`; `uaanime doctor` теж її знає. Там же, під адресою,
екран «Грає» малює QR-код — наведіть камеру замість того, щоб набирати токен
руками. Відкрийте адресу в Safari на телефоні в тій самій Wi-Fi і додайте на
екран «Домівка» — порт і токен постійні, закладка переживає перезапуски.

Пульт автоматично підлаштовується під світлу або темну тему телефона. Повзунок
працює дотиком і клавіатурою. При втраті зв’язку останні назва й прогрес
залишаються видимими, а кнопки вимикаються до відновлення статусу. Команди
автоматично не повторюються.

Захист — лише секретний токен у посиланні, трафік відкритий: той, хто підгляне
адресу у вашій домашній мережі, зможе поставити на паузу чи перемкнути серію, і
більше нічого.

Режим пульта обирається на екрані «Налаштування» → «Режим» (або ключем `remote`):
«лише за посиланням» (`on`), «будь-хто в мережі» (`open`), «вимкнено» (`off`).
`open` прибирає токен: адреса стає `http://<ім'я-mac>.local:<порт>/`, зате керувати
плеєром зможе будь-який пристрій у тій самій мережі — вмикайте лише вдома. Порт і
токен зберігаються, тож повернення на `on` дає стару адресу. У режимі `open` пульт
відповідає лише за надрукованими адресами (`.local` та IP); інші імена хоста,
наприклад видані роутером, він відкидає — це захист від DNS rebinding.

Перший запуск може спитати дозвіл фаєрвола macOS на вхідні з'єднання — погодьтеся
один раз. Під час відтворення з іншого термінала доступні `doctor`, `search`,
`episodes`, `resolve`, `export` та `play --dry-run`: вони не змінюють бібліотеку
й не споживають журнал. Другий TUI, звичайний `play` або `import` відхиляється,
доки перший процес не завершиться. Після аварії блокування звільняє ОС.

Якщо запис прогресу не вдався, перегляд продовжується з попередженням, а запис
повторюється. Після відновлення збереження попередження зникає. Для технічних
подробиць помилок додайте `--debug` (працює і для TUI).

## Розробка

Для збірки потрібен Go 1.25+, для тестів JavaScript вебпульта — Node.js 22+.
Node.js не потрібен користувачам готового бінарника; npm-залежностей немає.

```bash
make build   # bin/uaanime
make test    # без мережі, фікстури в testdata/
make lint    # gofmt + go vet + golangci-lint
```

`UAANIME_FIXTURES=1` — провайдер читає збережені сторінки замість мережі.
`make record-fixtures` — переписати фікстури з живого сайту (вручну, не в CI);
`make record-fixtures-new` — дописати лише нові, не чіпаючи наявних регресійних.
Як лагодити парсер після зміни сайту — `.claude/skills/provider-repair/SKILL.md`.

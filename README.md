# uaanime

Дивись аніме **українською** просто з термінала: озвучення різних студій і субтитри,
з пам'яттю про те, де ти зупинився і чию озвучку любиш.

```
uaanime → Продовжити → Enter → грає
```

На відміну від ani-cli, uaanime пам'ятає **стан**:

- ▶ **Resume** — вийшов на 14:32, наступний запуск продовжить звідти (±5 с, навіть після `kill -9`);
- 🎙 **Твоя студія** — обрав FanVoxUA один раз, далі всі серії йдуть нею без питань;
- 📚 **Список перегляду й історія** — все локально, офлайн, без акаунтів і телеметрії;
- 🔔 **Оновлення** — бачиш, скільки нових серій вийшло у тайтлів, які дивишся;
- 🔁 **Fallback** — мертвий відеохост підмінюється іншим мовчки.

## Встановлення

**macOS і Linux (Homebrew):**

```bash
brew tap Basmanjacks/uaanime
brew install --cask Basmanjacks/uaanime/uaanime
```

Одна команда на обидві системи: Homebrew 6 підтримує casks і на Linux. Сторонні
tap воно автоматично не додає, тому перший рядок обов'язковий. Хочеш коротке ім'я
надалі — виконай `brew trust basmanjacks/uaanime`, і далі працюватиме просто
`brew install --cask uaanime`. Якщо ти ставив uaanime раніше формулою
(`brew install …` без `--cask`), перейди на cask:

```bash
brew uninstall uaanime && brew install --cask Basmanjacks/uaanime/uaanime
```

Для відтворення потрібен VLC або mpv. Якщо плеєра ще немає, на macOS:

```bash
brew install --cask vlc
# або
brew install mpv
```

VLC, встановлений вручну з сайту VideoLAN у `/Applications/VLC.app`, теж працює —
перевстановлювати або передавати його під керування Homebrew не потрібно.

**Без Homebrew** — через Go або tarball з Releases:

```bash
go install github.com/Basmanjacks/uaanime/cmd/uaanime@latest
# або візьми готовий бінарник із GitHub Releases
```

На Linux та інших системах встанови [VLC](https://www.videolan.org/vlc/) або
[mpv](https://mpv.io/) через пакетний менеджер своєї ОС.

`uaanime doctor` перевірить, чи все на місці.

## Використання

```bash
uaanime                # TUI: Продовжити / бібліотека / пошук / історія / каталог / налаштування
```

Клавіші в TUI:

- `↑↓` — вибір, `Enter` — відкрити, **`Esc` — крок назад** (з тайтлу — в результати
  пошуку, з них — на головну), `?` — довідка поточного екрана, `/` — пошук
  (у серіях, закладках та історії — фільтр),
  `m` — додати/прибрати закладку зі станом «в планах», `s` — на екрані серій обрати
  реліз: студію **і** тип, озвучення чи субтитри (закріплюється за тайтлом),
  `D` — на екрані серій зберегти серію на диск (переклад → якість → у чергу), на домівці,
  у закладках, історії та пошуку — екран «Завантаження» (там `Enter` грає, `X` прибирає),
  `,` — налаштування, `r` — оновити зараз (на головній і в закладках — усю
  бібліотеку й каталог, на екрані серій — цей тайтл), `q` — вихід.
- Нові серії підтягуються самі: поки застосунок запущений, бібліотека
  перевіряється у фоні й нова серія з'являється в бейджах «+N нових серій»
  протягом приблизно години; після завершення серії список тайтлу
  перевіряється одразу («з'явилась серія 12»). `r` — коли чекати не хочеться:
  статус покаже «Оновлюю…» → «Оновлено · +2 нові серії».
- Екран «Грає» — плеєр слухається термінала: `Space` — пауза, `←→` — ±10 с,
  `⇧←→` — ±30 с, `N` — наступна серія, `.` — досидіти цю серію й зупинитись
  (повторне натискання вимикає обмеження), `B` — ліміт сеансу, `+`/`−` — гучність.
  Видно фактичну студію, позицію, паузу, гучність і час завершення, якщо тривалість
  відома. Адреса пульта й QR-код займають вільне місце.
- `B` задає від 1 до 12 серій **разом із поточною**, або «Без ліміту». Ліміт 2
  дограє поточну й наступну навіть при вимкненому автопереході. Ручне перемикання
  замінює поточну серію й не витрачає залишок. `.` при ліміті 2–12 встановлює 1.
  Ліміт діє лише на цей сеанс і доступний навіть із вимкненим веб-пультом.
- У довідці `Esc` закриває лише довідку; перегляд продовжується. Пауза, наступна
  серія, гучність і `.` працюють у довідці, стрілки пересувають її список.
- Екран серій: кожен рядок каже, що саме ввімкне `Enter` — `Озв · Рідний Голос ·
  ще 1 озв · 1 саб` (токени: `Дуб`, `Озв`, `Саб`, `Мікс`). Якщо серія вийшла лише в
  субтитрах, а ти дивишся в озвученні, рядок попереджає червоним «озвучення ще не
  вийшло»; після `Enter` те саме пояснює статус, а на екрані «Грає» реліз стоїть одразу
  після номера серії. `x` — позначити серію переглянутою або скинути позначку.
  У заголовку — скільки серій лишилось, приблизно скільки це часу і закріплений реліз
  (`реліз: Рідний Голос · Озв`). У виборі релізу (`s`) кожна пара «студія · тип» —
  окремий рядок із покриттям виду `9/12`: `✓` — закріплено, `▶` — гратиме для цієї
  серії, «немає в цій серії» — пара є в інших серіях. Явний вибір субтитрів
  поважається навіть коли є озвучення; неявно (після першого перегляду) субтитри
  ніколи не закріплюються.
  `W` позначає всі наявні серії перед вибраною, навіть під час фільтрації; `U`
  скасовує цю групову дію. Подальша зміна цього тайтлу або запуск перегляду
  скасовує можливість відкату. Мала `u` залишається переходом на сторінку вгору.
- Пошук: `↓` з поля відкриває 5 нещодавніх запитів, `Enter` повторює запит,
  `x` прибирає рядок з історії.
- Домівка: до трьох рядків «Продовжити» і п’яти закладок; новинки — першими.
  «Усі закладки» відкриває повний список із фільтром. Рядок «Що подивитись?»
  витягує випадковий тайтл із планів. Банер міняє орнамент за порою року.
- Історія показує по 20 тайтлів. «Показати ще» додає наступну порцію, а `/` шукає
  одразу в усій історії. Повернення з тайтлу зберігає фільтр і вибраний рядок.
- Екран «Налаштування» (рядок у секції «Ще» або `,`): плеєр, наступна серія, що
  вмикати спершу, улюблена студія, режим пульта, папка завантажень. `←→` перемикає значення на місці,
  `Enter` відкриває список значень із поясненнями. Зміни зберігаються одразу; пульт
  перезапускається на льоту, і нова адреса видна просто на екрані.
- Бейдж «+N у <студія>» показує нові релізи закріпленої або улюбленої студії,
  зокрема пізні озвучення старих серій. Нова серія лише в субтитрах ніколи не
  ховається за ним: «+1 лише в субтитрах» (червоним) або «+1 у <студія> · +1 лише
  в субтитрах». За відсутності таких релізів показуються загальні нові серії.
  У «Продовжити» біля тайтлу видно, у якому релізі відкриється наступна серія. Перші відомі дані стають початковою базою без сповіщень.
  Відкриття тайтлу «в планах» підтверджує його релізи; для розпочатого тайтлу
  підтверджуються переглянуті або вручну позначені серії. Фонове оновлення
  перевіряє до 20 застарілих тайтлів за один прохід (на старті й далі кожні 10 хв) і продовжує обхід наступного разу.
- Блоки «Топ сезону» і «Нові релізи» тягнуться з кешу (TTL 12 год) і оновлюються
  фоном — головна відкривається миттєво навіть без мережі.

Іконки — звичайний Unicode без емодзі; `UAANIME_ASCII=1` перемикає на чистий ASCII.
Шрифт задає термінал, не застосунок: якщо вирівнювання «їде», спробуйте
моноширинний шрифт із повним покриттям Unicode (наприклад, JetBrains Mono).

Headless-команди (для скриптів і перевірок):

```bash
uaanime search "фрірен" --json
uaanime episodes <title-id> [--fresh] --json
uaanime resolve <title-id> <серія> [--studio назва] [--kind тип] --json
uaanime play <title-id> <серія> [--dry-run]
uaanime download <title-id> <серія> [--studio назва] [--kind тип] [--quality 1080] [--dir шлях] [--json]
uaanime downloads [--dir шлях] [--json]
uaanime doctor
uaanime export > backup.json
uaanime import backup.json
uaanime version [--json]     # або uaanime --version
```

`episodes --json` дає кожному релізу серії поле `playable`: `true`, якщо хоч одне його
джерело лежить на відеохості, який uaanime уміє відтворити, і `false`, якщо реліз є на
сайті, але лише на непідтримуваному хості (`resolve` і `download` його не повернуть).
Перевірка без мережі, за адресою плеєра. Поля немає лише тоді, коли це невідомо: немає
мережі, а кеш записано старою версією. У текстовому виводі такі релізи позначені «хост не
підтримується». Список серій кешується на годину; `--fresh` іде на сайт в обхід кешу.

Під `--json` помилка будь-якої headless-команди — один рядок на stderr, stdout порожній,
код виходу той самий (1 — збій, 2 — помилка вжитку):

```json
{"error":{"code":"host_unsupported","message":"для серії є релізи, але жоден відеохост поки не підтримується"}}
```

`message` — той самий текст, що без `--json`. Коди: `offline` (немає мережі), `provider`
(сайт не відповів як слід), `no_stream` (серії чи потоку немає), `host_unsupported` (релізи
є, але жоден відеохост не підтримується), `release_unavailable` (запитаного релізу немає),
`quality_missing` (запитаної якості немає), `cancelled`, `usage` (неправильні аргументи),
`internal`; для завантаження ще `already_saved`, `download_busy`, `disk_full`,
`no_write_access`, `stream_encrypted`, `stream_unsupported`, `stream_expired`, а також
`store_busy`, `no_player`, `player`, `saved_file_missing`.

`download` зберігає одну серію у `download_dir` (або в `--dir`): без `--quality` береться
найкраща доступна, у процесі друкується рядок прогресу. `Ctrl+C` перериває завантаження
і прибирає незавершений файл — на диску не лишається нічого.
Числова `--quality` означає точну якість: якщо вона недоступна, інша не підставляється.
Під `--json` команда друкує один об'єкт: `path`, `bytes`, `height`, `seconds` і що саме
збережено — `id`, `episode`, `studio`, `kind` (ті самі значення, що в службовому файлі серії).

Без прапорців реліз обирається так само, як для перегляду (пін тайтлу, улюблена студія,
бажаний тип). `--studio` і `--kind` задають його явно — і для `download`, і для `resolve`
(щоб перевірити доступність без завантаження):

- `--kind dub|voiceover|sub` — лише цей тип; `--kind voiced` — будь-яке озвучення (дубляж
  чи закадрове), найкраще за звичним порядком; субтитри й `multi` не підставляються;
- `--studio <назва>` — лише ця студія (без урахування регістру); тип — за звичними
  правилами: субтитри цієї студії беруться, лише коли в серії немає озвучення, яке можна
  відтворити, або в налаштуваннях обрано субтитри; разом із `--kind` — точна пара;
- якщо запитаного релізу немає, його відеохост не підтримується або всі потоки мертві,
  нічого не завантажується (ані файла, ані теки), код виходу 1, а під `--json` — помилка
  `release_unavailable` або `host_unsupported`. Інший реліз мовчки не підставляється.

Прапорці діють лише на цей запуск: пін, бібліотека й `config.json` не змінюються.

`downloads` показує, що вже лежить у `download_dir` (або в `--dir`): лише читає диск, без
мережі. Текстом — по рядку на файл (title-id, серія, переклад, якість, шлях). Під `--json` —
масив тайтлів, відсортований за назвою, серії — за номером, файли — за шляхом:

```json
[{"id": "anitube:6108-psay", "name": "Псайрен", "folders": ["/…/Псайрен"],
  "episodes": [{"number": 6, "files": [{"path": "/…/Псайрен - 06 - Рідний Голос [Озв, 1080p].ts",
     "studio": "Рідний Голос", "kind": "voiceover", "height": 1080, "bytes": 393872408,
     "modified": "2026-11-16T19:09:58Z", "known": true}]}]}]
```

`modified` — час зміни файла в UTC (RFC 3339). `known: false` — файл без службового файла
серії: номер серії й якість узято з імені, `studio` і `kind` порожні. Теки, яких uaanime не
створював (без службових файлів), не показуються; відсутня папка — порожній масив.

Дані живуть в одному каталозі (`~/Library/Application Support/uaanime` на macOS) —
`export`/`import` переносять усе.

Налаштування зручніше міняти в самому застосунку: екран «Налаштування» — рядок
у секції «Ще» на домівці або клавіша `,`. Для headless-режиму ті самі значення
лежать у `config.json` у цьому ж каталозі:

- `player`: `vlc` або `mpv`; за замовчуванням `vlc`;
- `autoplay`: `always` або `never`; за замовчуванням `always` — наступна серія
  стартує автоматично;
- `prefer_kind`: `dub`, `voiceover` або `sub`; за замовчуванням `dub` — що обирати,
  коли для серії є кілька варіантів озвучення;
- `favorite_studio`: назва студії озвучення; порожньо = не вибрано;
- `remote`: `on`, `open` або `off`; за замовчуванням `on` — веб-пульт для телефона (нижче);
  `open` — той самий пульт без токена в адресі;
- `download_dir`: абсолютний шлях; за замовчуванням `~/Movies/uaanime` (macOS) або
  `~/Videos/uaanime` (Linux) — куди зберігаються серії, кожен тайтл у своїй підпапці.

## Завантаження

`D` на екрані серій (або команда `download`) зберігає серію у свою підпапку тайтлу:
`<Назва> - 05 - Студія [Озв, 1080p].ts`. HLS склеюється в один `.ts` без перекодування —
такий файл грають і VLC, і mpv; прямі файли (mp4/webm) зберігаються як є.

У TUI спочатку обирається студія й тип перекладу, потім якість. Цей вибір не змінює
закріплений переклад для перегляду. Одну серію можна зберігати в кількох перекладах
і якостях; наявні варіанти позначаються у списку. Повтор невдалого завантаження
зберігає початковий переклад, якість і папку.

Поруч із серією лежать приховані службові файли: `.<ім'я файла>.json` біля кожної серії,
`.uaanime-title.json` у папці тайтлу і `.uaanime/locks/` у корені папки завантажень.
Не видаляйте їх — саме за ними застосунок упізнає збережену серію (студію, тип, якість)
навіть після того, як сайт перейменує тайтл. Самі відеофайли — ваші: перейменовуйте,
переносьте й видаляйте як завгодно, застосунок їх не чіпає.

Завантажувач навмисно ігнорує проксі з оточення (`HTTP_PROXY`/`HTTPS_PROXY`) — він сам
перевіряє, що адреса, куди йде запит, публічна. Під час перегляду файл із диска
використовується лише для обраної студії й типу перекладу; інакше шукається потрібний
реліз онлайн. Для точного локального збігу мережа не потрібна, а серед його якостей
береться найвища.

У «Завантаженнях» кожен файл має окремий рядок: `Enter` запускає саме його.
Наявний пін перегляду зберігається для наступних серій; якщо піна ще немає,
явний запуск відомого перекладу запам'ятовує його. Файл без достовірних метаданих
позначається як невідомий переклад і доступний для явного запуску.

## Веб-пульт

Ноутбук дзеркалиться на телевізор, а ви на дивані? Поки грає серія, uaanime тримає
крихітну сторінку в локальній мережі: пауза, ±10 і ±30 с, повзунок перемотування,
гучність, наступна серія, ліміт сеансу, «зупинити після цієї», стоп і список серій —
тап по рядку перемикає на неї. Адреса виду
`http://<ім'я-mac>.local:<порт>/r/<токен>` показується на екрані «Грає» і
друкується командою `play`; `uaanime doctor` теж її знає. Там же, під адресою,
екран «Грає» малює QR-код — наведіть камеру замість того, щоб набирати токен
руками. Відкрийте адресу в Safari на телефоні в тій самій Wi-Fi і додайте на
екран «Домівка» — порт і токен постійні, закладка переживає перезапуски.

Пульт автоматично підлаштовується під світлу або темну тему телефона. Повзунок
працює дотиком і клавіатурою. При втраті зв’язку останні назва й прогрес
залишаються видимими, а кнопки вимикаються до відновлення статусу. Команди
автоматично не повторюються.

Захист — лише секретний токен у посиланні, трафік відкритий: той, хто підгляне
адресу у вашій домашній мережі, зможе поставити на паузу чи перемкнути серію, і
більше нічого.

Режим пульта обирається на екрані «Налаштування» → «Режим» (або ключем `remote`):
«лише за посиланням» (`on`), «будь-хто в мережі» (`open`), «вимкнено» (`off`).
`open` прибирає токен: адреса стає `http://<ім'я-mac>.local:<порт>/`, зате керувати
плеєром зможе будь-який пристрій у тій самій мережі — вмикайте лише вдома. Порт і
токен зберігаються, тож повернення на `on` дає стару адресу. У режимі `open` пульт
відповідає лише за надрукованими адресами (`.local` та IP); інші імена хоста,
наприклад видані роутером, він відкидає — це захист від DNS rebinding.

Перший запуск може спитати дозвіл фаєрвола macOS на вхідні з'єднання — погодьтеся
один раз. Під час відтворення з іншого термінала доступні `doctor`, `search`,
`episodes`, `resolve`, `export` та `play --dry-run`: вони не змінюють бібліотеку
й не споживають журнал. Другий TUI, звичайний `play` або `import` відхиляється,
доки перший процес не завершиться. Після аварії блокування звільняє ОС.

Якщо запис прогресу не вдався, перегляд продовжується з попередженням, а запис
повторюється. Після відновлення збереження попередження зникає. Для технічних
подробиць помилок додайте `--debug` (працює і для TUI).

## Розробка

Для збірки потрібен Go 1.25+, для тестів JavaScript вебпульта — Node.js 22+.
Node.js не потрібен користувачам готового бінарника; npm-залежностей немає.

```bash
make build   # bin/uaanime
make test    # без мережі, фікстури в testdata/
make lint    # gofmt + go vet + golangci-lint
```

`UAANIME_FIXTURES=1` — провайдер читає збережені сторінки замість мережі.
`make record-fixtures` — переписати фікстури з живого сайту (вручну, не в CI);
`make record-fixtures-new` — дописати лише нові, не чіпаючи наявних регресійних.
Як лагодити парсер після зміни сайту — `.agents/skills/provider-repair/SKILL.md`.

## Правові зауваги

uaanime — лише термінальний клієнт до публічно доступних сайтів; він нічого не хостить,
не обходить захисти і не містить контенту. Збереження серії на диск відбувається виключно
за явною дією користувача, у його власну папку і для особистого перегляду — застосунок
нічого не завантажує сам і нічого не роздає. Повага до праці українських студій озвучення:
їхні назви завжди показуються як є.
